# Basic Neural network with a forward pass

This is a small feedforward neural network built from using NumPy.

Here, the deliverables 1.1 and 1.2 of Task 1 has been implemented.

## Layout of the repo

```
src/
  deliverable_1_1_layers.py         (deliverable 1.1)
  deliverable_1_2_network.py   (deliverable 1.2)
test.py (Checking our network against PyTorch)
README.md                    
WRITEUP.md  
```

## Requirements

- Python 3.8+
- Numpy
- PyTorch


To install Numpy and PyTorch: 

```
pip install numpy torch
```

## How to run

Run the commands from the root of repository so that the
package imports resolve correctly.

For deliverable 1.1:
```
python -m src.deliverable_1_1_layers
```

For deliverable 1.2:
```
python -m src.deliverable_1_2_network
```

For test program:
```
python test.py
```
